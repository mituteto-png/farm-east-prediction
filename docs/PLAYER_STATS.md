# 個人成績・選手分析（2026-09-20）

## ページ
- `/stats/`: 全14球団の打者・投手一覧、検索、複合絞り込み、列ソート
- `/stats/titles/`: 3地区別の公式主要部門と規定到達ボーダー
- `/stats/prospects/`: U20/U23/U25、新人、育成、全選手の成績ランキング
- `/players/?id={recordId}`: NPB選手IDを基礎にした球団別選手成績詳細
- `/stats/compare/?role=batter&players={recordId,...}`: 2〜4選手の共有可能な比較

GitHub Pagesの直接アクセスと再読み込みに対応するため、実在するディレクトリの`index.html`を使用する。移籍時は同一NPB選手IDを保持しつつ、球団別成績レコードID（球団コード-NPB ID）を分ける。

## 共通計算
`player-metrics.js`が定義・表示桁・高低方向を一元管理する。

- OPS = 出塁率 + 長打率
- ISO = 長打率 - 打率
- BABIP = (安打 - 本塁打) / (打数 - 三振 - 本塁打 + 犠飛)
- BB%, K%, HR% = 各イベント / 打席
- WHIP = (被安打 + 与四球) / 投球回
- K/9, BB/9, HR/9 = 各イベント × 9 / 投球回
- K/BB = 奪三振 / 与四球
- 投手K%, BB%, K-BB%は対戦打者を分母とする

分母0と欠損は`null`とし、「—」表示。公式の0とは区別する。投球回は内部でアウト数を使用し、5.1回を16アウトとして処理する。年齢基準日は2026年10月1日。タイトル率部門の現在規定は球団消化試合×2.7打席、×0.8投球回を整数の到達可能値へ切り上げる。

## データ取得
`scripts/update-player-stats.mjs`がNPB公式の球団別打撃・投手・守備成績、球団選手一覧、2025ドラフト掲載名を取得する。14球団を順番に処理し、球団間に待機を入れる。ドラフトは初回取得後の新人名を再利用する。既存の順位結果・日本選手権更新とは別ファイル`player-stats-data.json`へ保存する。

取得失敗時は球団ごとに前回正常値を`stale`として保持する。個人成績処理はGitHub Actionsで`continue-on-error`とし、失敗しても順位予測の更新を止めない。

NPBの`robots.txt`は2026-09-20確認時に404で、個別のクロール指示は確認できなかった。公式ページのフッターには掲載情報の二次利用・無断転載を禁じる表示があるため、画像やページデザインは複製せず、取得頻度を既存の1日2回に限定し、出典リンクを表示する。公開運用では必要に応じてNPBへ利用条件を確認する。

## 選手経歴

`scripts/update-player-careers.mjs`がNPB公式の個人年度別成績ページをNPB選手ID単位で取得し、`player-career-data.json`へ分離保存する。経歴は30日キャッシュを使い、GitHub Actionsでは週1回だけ確認する。各レコードは`source`、`sourceUrl`、`lastChecked`を保持する。

- 収録：公式プロフィールの経歴順、ドラフト表記、身長、体重、生年月日、投打、守備位置、NPB一軍年度別成績で確認できた所属年度
- 未収録：出身地、支配下・育成の登録日、移籍日、加入経緯、在籍のみで一軍出場がない過去球団
- NPB公式の経歴欄に年次がない学校・社会人歴には年を補わず「プロ入り前」と表示する。
- ドラフトは公式表記から年度・順位・通常／育成を解析するが、指名球団は公式プロフィールに項目がないため推測しない。
- オイシックス・ハヤテ所属選手などNPB選手IDを確認できない選手は自動照合対象外とする。

オイシックスとハヤテはNPB球団選手一覧ページがないため、公式ファーム成績の全出場選手を収録する一方、背番号・生年月日・投打・支配下/育成・新人区分は未確認として保持する。架空値では補完しない。

## 選手比較

- 比較は既存の`player-stats-data.json`と`player-metrics.js`をそのまま使用し、別計算式を持たない。URLの`players`に球団別レコードIDを最大4件保持する。
- 比較候補はブラウザ内だけに保存し、公式成績や自動更新データは変更しない。打者・投手は混在させず、2〜4人を比較する。
