# 2026-09-05 追加分析とページ構成

ホーム(index.html)、優勝予測(prediction.html)、シミュレーター(simulator.html)、日本選手権(farmchamp.html)、全14球団(power-ranking.html)、説明(about.html)の6ページ。共通選択はURLとlocalStorage、共通UIはsite.js/pages.css、V3.0計算はmodel-core.js。旧app.jsと公式結果データ・取得処理は変更しない。

## 新しい分析
- Farm Championship Model v1.0: 20,000回の残りシーズン、地区優勝3球団と最高勝率2位のワイルドカード、準決勝2対3・1対WC、決勝を計算。総合タイトル確率=進出率×条件付き優勝率。中立地。公式同率細則は勝数・乱数で近似。雨天・延長方式・資格選手別の戦力は未反映。
- ボーダー: 予測最終チーム試合数から既存の資格判定を利用。12打席/9アウト以内をボーダー。他は過去1出場平均×残り試合でペース比較。打席や延長の架空上限から到達不能と断言しない。
- シミュレーター: 選択結果を複製データの勝敗分に反映し対象日程を除外。得失点は入力されないため保持。残りをV3.0で20,000回再計算。公式データを書き換えない。
- ベストメンバー: 既存資格判定eligible=trueの選手のみ。暫定規定クリアは含まない。OBP/SLGと打席信頼度、ERA/WHIPと投球回信頼度から選出。大分類の守備位置を使用。詳細位置、最近の起用、先発履歴、故障は未取得。欠員は空席。
- Power Ranking Model v1.0: 既存地区指数と同じ球団評価(勝率40%、ピタゴラス35%、得点力15%、失点抑制10%)。100は全構成指標の理論上限で、最強球団に強制的に100を付与しない。地区指数はその単純平均。相手補正・直近状態・前回順位はこの指標には未反映。

## データと更新
NPB公式3地区成績・日程(auto-data.js)、資格名簿/公示(farmchamp-data.js)、公式球団別ファーム打撃/投手成績(analysis-data.json)。追加成績はscripts/update-analysis-data.mjsで候補球団を取得し既存選手IDに照合。取得失敗時は前回値とerrorを保持。更新時刻は既存8時/17時を維持。選手資格は既存取得データに依存しNPB最終出場名簿ではない。
